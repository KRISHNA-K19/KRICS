## Brand & Style

This design system establishes a high-performance, futuristic glassmorphic workspace tailored for intelligent career navigation, skill tree synthesis, and career telemetry. It unites atmospheric cosmic depth with rigorous enterprise ergonomics.

### Personality & Tone
- **Visionary yet Grounded:** Futuristic aesthetic driven by technical clarity rather than decorative sci-fi tropes.
- **Precision & Authority:** High information density presented with serene legibility and luminous visual hierarchy.
- **Empowering & Telemetric:** Interfaces feel like an orbital navigational bridge—monitoring skill acquisitions, career trajectories, and system telemetry in real time.

### Visual Style Model
- **Atmospheric Cosmic Glassmorphism:** Deep space canvases anchored by layered translucent panels, variable frosted backdrops, subtle specular inner highlights, and faint ambient radiant fields.
- **Calibrated Ergonomic Ratio:** 70% functional utility and information clarity, 20% atmospheric space depth, and 10% luminous electric accents.

## Colors

The palette operates on high-contrast celestial illumination against layered cosmic abyssal tones.

### Color Tiers & Palette Roles
- **Base Canvas:** `#0b0d1a` (Deep Void) provides the absolute baseline canvas.
- **Surface Elevation:** `#10131f` (Abyssal Surface) defines the secondary ground layer and floating dock bases.
- **Primary Electric Accent (`#38bdf8`):** Serves as the primary operational beacon—used for core interactive controls, active pathways, and primary focal highlights.
- **Secondary Atmospheric Accent (`#7c3aed`):** Drives systemic roadmaps, skill trees, complex mastery nodes, and high-tier milestones.
- **Tertiary Velocity Accent (`#06b6d4`):** Used for real-time telemetry, data flow indicators, and dynamic metrics.
- **Functional Semantics:**
  - **Verified / Aligned (`#10b981`):** Validated competencies, unlocked milestones, and optimal trajectory paths.
  - **Gap Alert / Diagnostic (`#f59e0b`):** Skill discrepancies, pending certifications, and trajectory pivots.
  - **System Critical (`#ef4444`):** Stalled milestones, deprecated proficiencies, or disconnected prerequisites.

## Typography

The typographic hierarchy is segmented into three distinct functional disciplines:
- **Navigational & Display Headings (Space Grotesk):** Engineered with crisp geometric apertures to give career titles, module headings, and system milestones a forward-leaning, architectural aura.
- **Operational UI & Long-form Narrative (Inter):** Highly legible, neutral sans-serif delivering fatigue-free reading for roadmaps, skill descriptions, feedback logs, and interaction triggers.
- **Instrument Telemetry & Identifiers (JetBrains Mono):** Monospaced precision reserved for data points, percentage tracking, node UUIDs, status timestamps, and technical matrix metrics.

## Layout & Spacing

The structural layout uses an adaptable 12-column grid system calibrated to support high-density telemetric dashboards, interactive skill graph visualizers, and linear career milestones.

### Structural Breakpoints
- **Mobile (< 768px):** 4-column flow, edge margin `margin-mobile` (1rem), stacked cards, full-width glass sheets.
- **Tablet (768px - 1024px):** 8-column layout, 1.5rem margins, split-pane navigation panels with condensed sidebars.
- **Desktop (> 1024px):** 12-column fluid grid, `margin` (2rem), fixed telemetry rails, and multi-axis roadmap viewports.

### Spacing Philosophy
- Dense grouping (`space-xs` and `space-sm`) binds closely coupled data elements, such as skill badges, node telemetry metrics, and input decorators.
- Structural breathing room (`space-md` through `space-xl`) isolates independent glass modules, creating distinct functional islands over ambient background glows.

## Elevation & Depth

Visual hierarchy uses luminous optical glass tiers layered over subtle, diffused cosmic energy fields.

### Layering Archetypes
- **Tier 0 (Void Ground):** Color `#0b0d1a` overlaid with faint radial gradient glows (electric blue `#38bdf8` at 6% opacity, violet `#7c3aed` at 4% opacity) acting as ambient background nebulae.
- **Tier 1 (Surface Glass Panels):** Background `rgba(16, 19, 35, 0.65)` with backdrop filter blur set between `20px` and `28px`. Enclosed with a 1px border gradient transitioning from top-left `rgba(255, 255, 255, 0.12)` to bottom-right `rgba(56, 189, 248, 0.08)`. Outer shadow: `0 8px 32px 0 rgba(0, 0, 0, 0.45)`.
- **Tier 2 (Elevated & Active Panels):** Background `rgba(22, 27, 48, 0.75)` with `28px` blur. Border stroke increases to `rgba(56, 189, 248, 0.35)` with an inner specular line highlight `inset 0 1px 0 rgba(255, 255, 255, 0.2)`. Outer shadow: `0 16px 40px 0 rgba(0, 0, 0, 0.55)`, accompanied by a diffuse cyan/blue glow `0 0 24px rgba(56, 189, 248, 0.15)`.
- **Tier 3 (Floating Overlays, Modals, Command Palette):** Background `rgba(16, 19, 35, 0.88)` with `32px` blur, 1px border of `rgba(56, 189, 248, 0.5)`, drop shadow `0 24px 64px 0 rgba(0, 0, 0, 0.75)`.

## Shapes

The geometric architecture pairs precise optical rounding with clean edges to preserve an advanced instrument aesthetic.

### Corner Radii
- **Standard UI Elements (`0.5rem` / `8px`):** Input fields, interactive action buttons, chips, contextual tooltips, and table row groupings.
- **Intermediate Modules (`rounded-lg` / `1rem` / `16px`):** Skill cards, telemetry modules, career roadmap milestones, modal viewports.
- **Structural Canvas Shells (`rounded-xl` / `1.5rem` / `24px`):** Master dashboard wrappers, telemetry docks, floating bottom bars.

## Components

### Buttons
- **Primary Beacon:** Background gradient `linear-gradient(135deg, #38bdf8 0%, #2563eb 100%)`, text `#0b0d1a` (bold Inter), 1px highlight border `rgba(255, 255, 255, 0.4)`, subtle cyan box-glow `0 0 16px rgba(56, 189, 248, 0.35)`.
- **Secondary Glass:** Background `rgba(16, 19, 35, 0.65)`, backdrop blur `16px`, 1px border `rgba(255, 255, 255, 0.12)`, text `#f8fafc`. Hover triggers border transition to `rgba(56, 189, 248, 0.4)` and ambient inner glow.
- **Ghost Action:** Background transparent, text `#94a3b8`, hover text `#38bdf8` with background `rgba(56, 189, 248, 0.08)`.

### Chips & Telemetry Tags
- Compact pills with `0.5rem` corner radius, padding `0.25rem 0.625rem`.
- Background `rgba(16, 19, 35, 0.6)` with a 1px matching border.
- Text rendered in `JetBrains Mono` (`telemetry-sm`).
- **Variants:**
  - *Skill Active:* Electric blue glow (`#38bdf8` text, `rgba(56, 189, 248, 0.15)` fill).
  - *Verified Competency:* Emerald glow (`#10b981` text, `rgba(16, 185, 129, 0.15)` fill).
  - *Gap Alert:* Amber glow (`#f59e0b` text, `rgba(245, 158, 11, 0.15)` fill).

### Cards & Roadmap Nodes
- Constructed with Tier 1 and Tier 2 glass panels.
- Contain a header row displaying a `Space Grotesk` title paired with a `JetBrains Mono` status identifier or progress percentage.
- Hover interactions trigger a subtle vertical lift (-2px) and an increase in the outer radiant cyan/violet glow border.

### Input Fields
- Background `rgba(16, 19, 35, 0.5)`, backdrop blur `12px`, 1px border `rgba(255, 255, 255, 0.12)`.
- Text color `#f8fafc` using Inter `body-md`, placeholder color `#64748b`.
- Focus state expands border to `#38bdf8` with a focus ring of `0 0 0 3px rgba(56, 189, 248, 0.2)`.

### Checkboxes & Radio Controls
- Base container `1.125rem` square/circle, border `1px solid rgba(255, 255, 255, 0.2)`, background `rgba(16, 19, 35, 0.8)`.
- Checked state fills with `#38bdf8` showing an obsidian `#0b0d1a` check icon, accompanied by a `0 0 10px rgba(56, 189, 248, 0.5)` halo.

### Specialized System Components
- **Telemetry Progress Rail:** Slim 4px frosted channel containing a gradient fill (`#06b6d4` to `#38bdf8`) with an animated glowing leading edge.
- **Node Matrix Graph:** Glassmorphic skill tree cards connected via vector traces rendered in `rgba(56, 189, 248, 0.25)`, brightening dynamically to 100% cyan when hovered or active.
